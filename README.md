# 💧 Smart Water Reminder

A modern offline-first Flutter application that helps users build healthy hydration habits through smart reminders, personalized water goals, analytics, and gamification.

> **Built with Flutter • Provider • SQLite • Material 3 • flutter_local_notifications**

---

## ✨ Features

- 💧 Smart Hydration Reminders
- 🎯 Weight-Based Daily Water Goal
- 📊 Beautiful Analytics Dashboard
- 📅 Hydration History & Timeline
- 🏆 Gamification with XP & Achievements
- 🔔 Offline Local Notifications
- 🌙 Premium Light & Dark Themes
- 💾 Offline-first with SQLite

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Android Studio or VS Code
- Android Emulator or Physical Device

### Installation

```bash
git clone https://github.com/Mayurs26/Smart-Water-Reminder.git

cd Smart-Water-Reminder

flutter pub get

flutter run
```

---

## 🔔 Smart Reminder System

The app creates personalized hydration reminders using:

- Weight-based water calculation
- Wake-up & Sleep schedule
- Activity level
- Smart interval distribution
- Adaptive reminders throughout the day
- Offline local notifications

Instead of fixed hourly notifications, reminders are intelligently spaced for a more natural hydration experience.
